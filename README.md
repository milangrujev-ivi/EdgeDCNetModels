# EdgeDCNetModels

This repository contains a collection of neural network architecture implementations designed for image classification tasks. It includes Python scripts (.py) for building and configuring the models, along with their corresponding trained models provided in multiple formats, including .h5, .keras, and .tflite for deployment on various platforms.

The project supports both research and real-time edge applications, offering reproducible model creation, conversion pipelines, and lightweight versions optimized for on-device inference.
